# Conventions

## File naming

- `episodic/YYYY-MM-DD-<topic>.md`
- `semantic/<topic>.md`
- `procedural/<routine>.md`
- `identity/<aspect>.md`

## Citation rule

Every durable fact must reference its source file and, where possible, block/line numbers.

## Claim discipline

- Say what is simulated vs. what is proven.
- Label speculative content as speculative.
- Do not endorse claims beyond `identity/claim-boundary.md`.
